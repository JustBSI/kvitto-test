# Журнал использования ИИ

Инструмент: Codex в PyCharm.
Модель: GPT-6.1 Sol, уровень рассуждения High.

Ключевые запросы (краткое изложение):

1. Изучить исходное техническое задание, определить требования, спланировать
   архитектуру и этапы реализации; подготовить TASK.md, AGENTS.md, README.md
   и AI_LOG.md.
2. Реализовать проект в соответствии с требованиями TASK.md и правилами
   разработки, определёнными в AGENTS.md.
3. Сверить реализацию с планом и техническим заданием, выявить несоответствия
   и ошибки, затем исправить их.
4. Подготовить проект к сдаче и опубликовать его код в публичном репозитории
   GitHub.

Ошибки и слабые решения ИИ:

- Не был ограничен tariff_id диапазоном PostgreSQL Integer. Проверка
  ID 2147483648 выявила 500; добавили верхнюю границу и регрессионные тесты.
  Теперь ответ — 422, данные не меняются.
- Docker quick start требовал локальные uv и venv. Человек заметил лишнюю
  зависимость; генерацию .env и утилиты перенесли в контейнеры.
- Внешний аудит выявил маскирующий seed в фикстуре, недетерминированный тест
  webhook и неточность OpenAPI. Исправили фикстуру, добавили проверки startup
  и ожидания блокировки, объявили подпись обязательной, сохранив 401 без неё.

Проверка: 142 теста прошли локально и в Docker, обе проверки Ruff успешны.
Проверены Alembic, Compose, живой API и HMAC. Новые тесты выявляют отключение
seed и FOR UPDATE. Опубликованный [GitHub Actions](https://github.com/JustBSI/kvitto-test/actions/runs/37143328937)
проверил 138 тестов; последние исправления пока не проверялись в CI.
